# Two Witnesses

Evidence Coalition Explorer for the Apart Research x CeSIA AI Incident Response Sprint.

The artifact accompanies the research paper "Two Witnesses: An evidentiary coalition audit of AI-agent incident disclosure."

## Running locally

Open `index.html` in a browser.

No backend or installation is required.

## What it does

The explorer lets readers toggle developer evidence, independent evidence, and the connection between the two sides to inspect how the 32 coded incident claims change under evidence removal.
